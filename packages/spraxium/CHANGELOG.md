# @spraxium/rpc

## 0.10.0

- Run authenticated provider methods in a Spraxium bot and route guild calls to the owning shard.
- Use framework 0.10.x and Discord.js 14.28.1 or a compatible 14.x release.
- See the [HTTP migration guide](https://spraxium.com/en/guide/rpc-http-migration) to move an existing route to RPC.
